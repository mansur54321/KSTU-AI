# Changelog

Все заметные изменения расширения KSTU-AI документируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
версионирование — [SemVer](https://semver.org/lang/ru/).

## [3.7.0] - 2026-08-15

### Security

- Расширение больше не отправляет публичный write-токен в общий кэш ответов (токен был в каждом релизе и ничего не защищал).
- API-ключи Gemini перенесены из `chrome.storage.sync` в `chrome.storage.local` с одноразовой миграцией — ключи больше не синхронизируются между устройствами.
- Экспорт настроек больше не содержит API-ключи; импорт legacy-файла с ключами мигрирует их в `local` storage.

### Fixed

- Кэш ответов для `text_input` и `moodle_dd` (Drag & Drop): раньше эти типы вопросов никогда не кэшировались.
- `crypto.subtle` на http-страницах: добавлен детерминированный fallback-хэш, чтобы кэш не ронял вопросы на незащищённых порталах.
- Исправлено перевёрнутое сопоставление правильного ответа (`ans.text.includes(c)` → матч по id/нормализованному тексту).
- Pro-модель больше не делает лишний fallback на фатальные ошибки (400/401/403, невалидный ключ).
- `unlockSite()` больше не выполняется в iframe; Alt+click без фолбэка на первый вопрос.

### Changed

- Валидация формы сообщений в background (`ask_gemini`, `cache_lookup`, `cache_store`).
- Константы (retry, hotkeys, цвет маркера) сведены в `src/config.js` — устранён рассинхрон значений.
- Удалён мёртвый код: `cacheStore`, `localCacheStore`, неиспользуемые CSS-правила.

### Added

- Поведенческие тесты кэша (нормализация, хэширование, legacy-ключи, маппинг текстов/пар) — 16 тестов суммарно.
