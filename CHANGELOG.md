# Changelog

Все заметные изменения расширения KSTU-AI документируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
версионирование — [SemVer](https://semver.org/lang/ru/).

## [3.9.0] - 2026-10-23

### Added

- Автоматическая проверка ответов Platonus после появления итогового отчёта, включая переход к результатам без перезагрузки страницы.
- Подтверждение по правильным вариантам или явному результату отдельного вопроса. Полностью правильная попытка подтверждает известные выбранные варианты; частичная общая оценка сохраняется только как статистика.
- Отправка подтверждённых ответов в существующий серверный кеш с ожиданием подтверждения записи и ограниченными повторами при ошибке.

### Fixed

- Подтверждённый ответ заменяет локальную догадку и имеет приоритет перед устаревшим серверным ответом.
- Набор вариантов, явно опровергнутый отчётом, исключается из локальной выдачи без удаления сохранённых данных.
- Последовательная запись в локальный кеш предотвращает потерю подтверждённых ответов при параллельных запросах.

## [3.8.0] - 2026-10-23

### Added

- Fast-режим Platonus заранее отправляет запросы для текущего и двух следующих вопросов, не переключая страницу ради предзагрузки.
- Для чтения уже загруженных вопросов Platonus добавлено разрешение `scripting` в пределах существующих разрешённых сайтов.

### Fixed

- `Alt + D` на Platonus распознаёт кнопки навигации и продолжает работу после смены вопроса без перезагрузки документа.
- Автопереход ждёт подтверждения сохранения ответа; при ошибке сохранения или загрузки останавливается.
- Предзагруженные ответы привязаны к ID вопроса и вариантов, учитывают перестановку вариантов и не перезаписывают ручной выбор.
- Повторное `Alt + D` не запускает второй проход, а завершение поддерживает окно подтверждения Platonus.

## [3.7.2] - 2026-10-23

### Changed

- Gemini 4 Argon (`gemini-4-argon`) заменяет Gemini 3.1 Pro и используется по умолчанию в Pro-режиме.
- Удалены переключатель старой Pro-модели и метка Legacy в настройках.
- Pro-таймаут определяется списком Pro-моделей, чтобы Argon сохранял лимит ожидания 240 секунд.

## [3.7.1] - 2026-09-04

### Changed

- Основная Gemini-модель и модель проверки ключей обновлены с `gemini-3.7-flash` до `gemini-3.8-flash`.
- Fallback остаётся `gemini-3.5-flash-lite`.

## [3.7.0] - 2026-08-15

### Security

- Расширение больше не отправляет публичный write-токен в общий кэш ответов (токен был в каждом релизе и ничего не защищал).
- API-ключи Gemini перенесены из `chrome.storage.sync` в `chrome.storage.local` с одноразовой миграцией — ключи больше не синхронизируются между устройствами.
- Экспорт настроек больше не содержит API-ключи; импорт legacy-файла с ключами мигрирует их в `local` storage.

### Fixed

- Кэш ответов для `text_input` и `moodle_dd` (Drag & Drop): раньше эти типы вопросов никогда не кэшировались.
- `crypto.subtle` на http-страницах: добавлен детерминированный fallback-хэш, чтобы кэш не ронял вопросы на незащищённых порталах.
- Исправлено перевёрнутое сопоставление правильного ответа (`ans.text.includes(c)` → матч по id/нормализованному тексту).
- Pro-модель больше не делает лишний fallback на фатальные ошибки (400/401/403, невалидный ключ).
- `unlockSite()` больше не выполняется в iframe; Alt+click без фолбэка на первый вопрос.

### Changed

- Валидация формы сообщений в background (`ask_gemini`, `cache_lookup`, `cache_store`).
- Константы (retry, hotkeys, цвет маркера) сведены в `src/config.js` — устранён рассинхрон значений.
- Удалён мёртвый код: `cacheStore`, `localCacheStore`, неиспользуемые CSS-правила.

### Added

- Поведенческие тесты кэша (нормализация, хэширование, legacy-ключи, маппинг текстов/пар) — 16 тестов суммарно.
